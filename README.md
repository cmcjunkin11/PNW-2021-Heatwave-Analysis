# [Read the full report analysis here.](Time_Analysis_of_PNW_2021_Heatwave.pdf)

This project takes a look at the Heatwave that occurred during the summer of 2021 in the Pacific Northwest region. The project contains a webscrape script suitable for Weather Undergrounds website (as api was not accessible during the time of this project), as well as Python scripts for analyzing the data collected from Weather Underground.

The webscraper saves in .csv format.
